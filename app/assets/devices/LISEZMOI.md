# Photos par type d'appareil

Déposez ici une photo par type d'appareil ; Solea l'affiche automatiquement sur chaque
appareil du même type qui n'a ni photo officielle (Tuya / Smart Life) ni photo prise par
l'utilisateur. Rien à changer dans le code : reconstruisez simplement l'application.

| Fichier                          | Appareils                                   |
|----------------------------------|---------------------------------------------|
| `air_conditioner.jpg`            | climatiseurs (modes froid, déshumidification, ventilation) |
| `thermostat.jpg`                 | thermostats, radiateurs                     |
| `camera.jpg`                     | caméras IP                                  |
| `light.jpg`                      | ampoules, plafonniers, rubans LED           |
| `plug.jpg`                       | prises et interrupteurs                     |
| `blinds.jpg`                     | volets, rideaux, stores                     |
| `lock.jpg`                       | serrures                                    |
| `door_sensor.jpg`                | capteurs d'ouverture                        |
| `motion_sensor.jpg`              | détecteurs de mouvement                     |
| `sensor.jpg`                     | capteurs de température / humidité          |
| `other.jpg`                      | autres appareils                            |

Formats acceptés : `.jpg`, `.png` (fond transparent conseillé) ou `.webp`, carré, environ
600 × 600 px et moins de 150 Ko. N'utilisez que des photos dont vous avez les droits
(vos propres photos de produits ou des photos libres de droits pour un usage commercial).
